# Quantity Measurement - Use Case 3

## 📌 Objective
Compare two length quantities with different units (Feet, Inch) by converting them into a common base unit.

---

## 📐 Supported Units
- FEET
- INCH

---

## ⚙️ Conversion Logic
- 1 FEET = 12 INCH
- Internally, all values are converted to FEET before comparison.
