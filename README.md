# Quantity Measurement - Use Case 4

## 📌 Objective
Support multiple units and compare them using a common base (Feet).

---

## 📐 Supported Units
- FEET
- INCHES
- YARDS
- CENTIMETERS

---

## ⚙️ Conversion Logic
| Unit | Conversion |
|------|------------|
| 1 Yard | 3 Feet |
| 1 Feet | 12 Inches |
| 1 CM | 0.0328084 Feet |

All values are internally converted to **Feet**.
